# 忆联 · 场景素材生成描述 V1.0

用途：交给 AI 绘图工具，批量生成"身后空间与居所"的成套场景照片（初稿，未经生成验证）。

配套阅读：`prototype/素材来源与授权.md`（为什么不能再从网上抓图）、`忆联_身后空间与居所设计_V1.0.md` 4.2–4.4。

---

## 一、先看这四条硬性要求，做不到的图直接废

1. **空镜**。画面里不能有人、宠物、车、船（有人的）、门牌号、招牌、文字、logo。人物涉及肖像权，文字和品牌涉及商标，门牌涉及隐私——这三样在生成阶段就要排除，不要指望后期修。
2. **窗户要"可见但不预先点亮"**。这是内容驱动机制的前提：家人的多少决定亮几扇窗。如果底图里窗已经全亮了，客户端再怎么加灯都看不出来。三个时段都要求窗户是可辨识的暗面。
3. **构图要给锚点留位置**。房屋正面（含每扇前窗和正面那扇门）必须清晰可见、大致均匀分布，且房子占画面宽度的 40%–55%、偏左或居中；画面下缘留出干净的地面或水面。我们后面要把窗灯、门口灯、长明灯锚在真实的窗户和门上——第一版原型锚点漂到树上，就是因为底图的窗和门不够清晰。
4. **一套场景三个时段必须是"同一栋房子"**。做法见第七节：固定随机种子，或者用清晨那张当参考图做图生图。

规格：横构图 16:9，出图不低于 1920×1080（我会裁成产品要的 1600×900）。

## 七、不同工具的实操

**Midjourney**：`--ar 16:9 --style raw --v 6.1`，再加一个固定 `--seed 12345`。先用清晨段出一张满意的，**记下 seed**，然后只替换光照段重跑，就能得到同一栋房子的黄昏与夜晚。

**Flux / Stable Diffusion**：1920×1080，steps 30–40，guidance 4–6，seed 固定。若换时段后房子变形，改用图生图：以清晨那张为参考图，denoise 0.4–0.55，光照段换成黄昏或夜晚。

**国内工具（即梦 / 通义万相 / 文心一格 / 豆包等）**：用中文段，尺寸选 16:9 / 1920×1080，风格选"写实 / 摄影"。多数不暴露 seed，就用"参考图 / 图生图"：拿清晨那张当参考，强度调到中低，再换光照描述。

**通用建议**：每个场景先生成 8–12 张挑 1 张。挑图的标准不是"好看"，而是第二节那条——**窗户和门清不清楚、房子是不是占了该占的位置**，因为后面要往上面锚灯。

## 八、挑图验收清单

- [ ] 画面里没有人、动物、车、文字、招牌、门牌号、logo
- [ ] 正面每一扇窗都清晰可辨，室内未点灯（夜晚版允许门边一盏小壁灯）
- [ ] 正面有一扇看得清的门
- [ ] 房子占画面宽度 40%–55%，偏左或居中，下缘有干净的地面或水面
- [ ] 横构图 16:9，长边 ≥1920
- [ ] 同一场景的三个时段是同一栋房子（屋顶形状、窗的数量与位置、烟囱、门的样式一致）
- [ ] 没有鱼眼畸变、地平线不歪、没有 HDR 光晕和过饱和
