## 一、项目目标与范围

### 1.1 目标

在 22 周内完成 MVP 开发，并以"1-2 家殡仪馆/公墓 + 50-100 个家庭"的规模完成试点，验证三组核心数据：

- 建档完成率 ≥ 60%
- 7 日留存 ≥ 30%，30 日留存 ≥ 15%
- 试点付费转化率 ≥ 5%

同时验证故事问答（文字）的满意度与合规可用性，跑通"扫码→建档→订单→分成结算"的渠道闭环，验证后台运营闭环（删除请求、投诉工单、问答审核、结算审核），形成可复制的 B2B2C 合作 SOP。

### 1.2 试点范围

- 试点地区：首选 1 个城市（建议一二线城市或其周边，殡仪馆/公墓合作意愿强的区域）。
- 试点机构：1-2 家殡仪馆或公墓。
- 试点家庭：50-100 个（每家至少 1 名创建者）。
- 试点功能：记忆档案、授权管理、家族共享、记忆馆（照片/原声录音/故事/纪念册）、节日关怀、设置中心、机构后台（仪表盘/员工/订单/结算/扫码物料）。
- 后台管理（内部）：数据看板、问答审核、删除工单、投诉工单、机构结算审核、审计日志。
- 灰度开放：故事问答（文字，前 20 个家庭，AI 标识 + 防沉迷）。
- 不开放功能：AI 语音朗读、声音克隆、影像复活（说话视频/动态影像/数字人形象）、AI 老照片修复。

### 1.3 成功标准（Go/No-Go 决策门）

| 指标 | 目标 | 判定 |
| --- | --- | --- |
| 建档完成率 | ≥60% | ≥5 项达标 → 进入扩展；2-4 项达标 → 调整后复测；≤1 项达标 → 暂停复盘 |
| 7 日留存 / 30 日留存 | ≥30% / ≥15% | 同上 |
| 试点付费转化率 | ≥5% | 同上 |
| 纪念册满意度 | ≥4/5（问卷） | 同上 |
| 故事问答满意度 | ≥4/5（问卷） | 同上 |
| 机构激活率 | ≥80% | 同上 |
| 删除请求 72 小时内处理率 | 100% | 同上 |
| 投诉率 | <1% | 同上 |
| 强制关闭请求处理时长 | ≤72 小时 | 同上 |

## 五、工作分解（WBS）

### WS1 商务与渠道

- 机构筛选标准：区域殡仪馆/公墓、数字化转型意愿、客单价结构、决策链长短。
- 关键任务：名单筛选 → 拜访演示 → 意向书 → 试点协议（含分成比例）→ 结算规则确认 → 机构培训 → SOP 沉淀 → 第二批机构候选名单。

交付物：机构候选名单、演示材料、试点协议、结算规则文档、机构培训手册、合作 SOP。

### WS2 合规与法务

- 关键任务：监管梳理 → 法律顾问咨询 → 《知情同意书》《用户数据使用协议》《AI 生成内容免责声明》《家族数据共管与删除规则》《未成年人保护说明》《机构合作协议与结算规则》《后台操作与审计规范》→ 故事问答安全评估 → 删除工单流程审核 → 备案材料准备。

交付物：合规检查表、法务文档包、安全评估报告、删除工单流程、备案材料。

### WS3 产品与设计

- 关键任务：用户旅程图 → 三端高保真原型（C 端/机构后台/后台管理）→ 文案与伦理话术（避免"复活"表述）→ 渠道角色与权限设计 → 后台角色与权限设计 → 故事问答提示词与回复风格 → 访谈提纲与问卷 → 数据看板定义。

交付物：原型（Figma）、文案库、角色权限表、问答风格配置、访谈提纲、指标字典。

### WS4 技术开发

- 关键任务：架构与数据库 → 后端 API → 移动端 → 对象存储 → 推送 → 故事问答（文字）接入 → AI 标识与防沉迷 → 纪念册模板 → 数据导出/删除 → 机构后台（仪表盘/员工/订单/结算）→ 后台管理（用户查询/问答日志/删除工单/结算审核/审计日志）→ 扫码物料 → 灰度开关。

交付物：代码仓库、API 文档、部署环境、机构后台 V1、后台管理 V1、功能开关配置。

### WS5 测试与质量

- 关键任务：功能测试 → 性能测试（首屏 <2 秒、问答 <15 秒、纪念册 <30 秒）→ 安全测试（越权、删除级联、不当内容拦截、机构越权、后台越权）→ 删除 SLA 与工单流程测试 → 结算对账测试 → 真机兼容（iOS 14+/Android 9+）→ 故事问答与纪念册满意度评估。

交付物：测试用例、性能报告、安全报告、删除 SLA 测试报告、结算测试报告、满意度报告。

### WS6 试点运营

- 关键任务：家庭招募 → 机构培训与上线配置 → 后台账号开通与工单演练 → 使用引导 → 数据回收 → 首月对账与结算 → 第 30/90 天回访 → 案例整理。

交付物：运营手册、数据看板、对账单、工单演练记录、回访记录、试点案例。

## 七、试点执行细则

### 7.1 机构合作流程

1. 拜访演示：用真实案例演示"记忆档案 + 纪念册 + 节日关怀 + 故事问答 + 机构后台"。
2. 签署试点协议：明确分成比例、数据权限、责任边界、退出条款。
3. 配置上线：开通机构账号与员工角色，生成机构二维码，配置分成比例。
4. 机构培训：前台/客服可独立完成"扫码 → 建档 → 授权"引导，并熟悉订单与结算查看方式。
5. 落地物料：机构二维码/纪念码、宣传单页、员工手册、对账模板。

### 7.2 家庭招募渠道

- 机构推荐（主要）：告别仪式前后由殡仪馆/公墓工作人员引导。
- 社区与公益：与安宁疗护、殡葬公益组织合作。
- 定向社交：清明/冬至前后在本地社群发布招募。

招募要求：创建者为直系亲属；有故人照片与 ≥1 段原声录音或文字故事；愿意接受 30/90 天回访。

### 7.3 转化漏斗与看板

漏斗：扫码到达 → 注册 → 建档 → 授权确认 → 首次使用 → 故事问答体验 → 回访/付费。

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 扫码到达率 | 扫码后打开页面比例 | ≥70% |
| 建档完成率 | 创建档案并上传 ≥1 素材的比例 | ≥60% |
| 授权完成率 | 完成知情同意的比例 | ≥90%（建档内） |
| 首次使用率 | 建档后 7 天内使用任一功能 | ≥70% |
| 故事问答使用率 | 建档后 7 天内发起 ≥1 次问答的比例 | ≥40%（灰度家庭） |
| 7/30 日留存 | 第 7/30 天有活跃行为的用户比例 | ≥30% / ≥15% |
| 付费转化率 | 试点期内付费家庭数 / 建档家庭数 | ≥5% |
| 机构激活率 | 签约后 2 周内完成配置并产生首个建档 | ≥80% |

### 7.4 反馈机制

- 第 1 周：使用体验访谈（10-15 人），覆盖操作、情感感受、授权理解。
- 第 30 天：问卷（满意度、NPS、纪念册与故事问答评价）。
- 第 90 天：深度回访（使用频率、退出意愿、建议）。
- 机构侧：每周与机构管理员同步订单、结算与问题反馈。
- 平台侧：每周运营复盘（删除工单、投诉、审核、结算状态）。
- 全程记录：投诉、求助、关闭请求的响应时长。

### 7.5 灰度与退出机制

- 故事问答：前 20 个家庭灰度；满意度 <4/5 或不当内容拦截不达标时暂停。
- 纪念册模板：先开放 1-2 个模板灰度，收集反馈后再扩展。
- 机构结算：试点期按月出对账单，金额不一致时暂停结算并人工核对。
- 后台工单：删除请求按 72 小时 SLA 执行，双人复核；试点期内至少完成一次全流程演练。
- AI 声音/影像功能：试点期不开放。
- 用户退出：任何家庭成员可申请关闭故事问答等 AI 能力；数据保留/删除由家族决定，删除 SLA ≤72 小时，机构不可拦截。
- 舆情预案：如发生"AI 复活"误解或负面传播，第一时间发布"记忆传承"定位说明、展示 AI 标识并暂停相关宣传物料。

## 八、试点风险与应对

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| 家庭招募不足 | 中 | 提前锁定 3 家机构备选；增加公益组织渠道 |
| 机构决策周期长 | 中 | 首周即拜访；用轻量"意向书"替代正式合同快速启动 |
| 合规事故（投诉/舆情） | 高 | 合规清单前置；专人响应；72 小时删除 SLA |
| 故事问答质量/不当内容 | 中高 | 质量门槛与人工复核；灰度观察；降级回模板化回复 |
| 用户心理风险 | 中高 | 防沉迷、AI 标识、极端情绪干预、回访记录 |
| 机构越权风险 | 中 | 角色权限表先行；操作审计；隐私内容默认不可见 |
| 结算纠纷 | 中 | 分成比例与对账口径写入协议；对账单可导出可审计 |
| 运营处置风险 | 中 | 删除/投诉未及时处理 | 工单 SLA、双人复核、后台演练 |
| 数据看板口径不清 | 低 | W3 前定义指标字典，统一埋点 |
