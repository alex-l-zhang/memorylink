## 二、产品愿景与使命

"当思念有声音，当回忆会说话。"

我们相信，死亡不是终点，遗忘才是。忆联致力于帮助家庭保存和传承亲人的记忆与故事，让亲情跨越时间，让后代有机会"认识"未曾谋面的长辈。

使用场景举例：

- 清明节自动收到家族共同整理的父亲叮嘱："孩子，天凉了，记得添衣。"（原声或家族撰写）
- 孙女在记忆馆里听爷爷留下的童年趣事原声录音。
- 孙女问"爷爷小时候最开心的事是什么？"，故事问答基于记忆档案以文字回答。
- 告别仪式上，大屏播放家族共同整理的纪念册与照片墙。
- 家属在殡仪馆扫码，由工作人员协助建档，全家共同维护记忆。
- 平台运营人员在后台处理删除请求、审核问答内容、核对机构结算。

设计原则：

- 情感真实，克制表达：MVP 不生成逝者声音与形象，文字故事问答带 AI 标识、可随时关闭。
- 家族共有：数据属于家族共有资产，共建共管；机构与平台员工均不可随意获取客户隐私内容。
- 伦理与合规优先：任何功能上线前先过"知情同意、数据可删除、防沉迷、AI 标识"四关。

- AI 语音朗读与声音克隆
- 影像复活：说话视频、动态影像、数字人形象
- AI 老照片修复
- 实时语音对话、多模态表情互动
- 家族知识图谱深度挖掘

说明：故事问答为 MVP 内唯一 AI 能力，仅限文字，不含任何声音/影像生成；其余能力列入后续迭代，需在伦理评审、合规备案与技术储备评估通过后启动。

## 五、核心页面与流程

### 5.1 主要页面

| 页面 | 功能描述 |
| --- | --- |
| 首页 | 今日纪念日、快捷入口、家族动态 |
| 记忆档案主页 | 查看故人信息、时间线、照片与录音 |
| 聊天界面（故事问答） | 文字输入，AI 回复，带 AI 标识与使用时长提醒 |
| 记忆馆 | 照片墙、原声录音库、故事集、纪念册 |
| 家族树 | 可视化家庭关系，邀请成员、权限管理 |
| 设置中心 | 隐私、权限、推送、问答开关、数据导出/删除、伦理开关 |
| 机构后台（B 端） | 仪表盘、员工管理、订单管理、结算中心、扫码物料（详见第七章） |
| 后台管理（平台端） | 数据看板、审核队列、删除工单、机构管理、结算审核、审计日志（详见第八章） |

### 5.2 关键流程

1. 创建记忆档案：选择创建者身份 → 填写故人信息 → 上传素材（照片/录音/故事）→ 知情同意确认（生前预授权或两名近亲共同确认）→ 生成时间线。
2. 家族共建：创建者邀请亲属 → 亲属实名验证 → 按角色获得共建或访客权限。
3. 纪念册制作：选择模板 → 选取素材 → 生成静态纪念册 → 可导出/打印。
4. 故事问答：进入对话 → 展示"AI 生成"提示 → 提问 → 基于记忆档案回复 → 连续使用超 2 小时提醒 → 检测到极端情绪时提供安抚与求助入口 → 可随时关闭。
5. 机构引导建档：家属扫码 → 进入机构专属纪念服务页 → 注册建档 → 知情同意由家属本人完成（机构可协助但不代签）。
6. 删除请求处理：家属申请 → 后台工单 → 合规专员核验 → 72 小时内删除 → 通知家属（详见第八章）。
7. 节日关怀：系统按事件日历生成提醒 → 默认每日 ≤1 条、夜间静音 → 用户可随时关闭。
8. 永久关闭：任意家庭成员申请 → 创建者与近亲确认 → 72 小时内处理（关闭故事问答等 AI 能力，删除或保留档案由家族决定，机构不可拦截）。

## 六、功能需求明细

### 6.1 用户系统（P0）

- 注册/登录：手机号+验证码、微信授权。
- 年龄核验：实名信息用于未成年人保护判断。
- 家庭关系：用户可绑定"我与故人的关系"（子女/孙辈/配偶等）。

验收标准：注册 60 秒内完成；未成年人账号不开放故事问答。

### 6.2 记忆档案（P0）

- 故人信息：姓名、生卒年月、籍贯、生平简介、关系标签。
- 素材上传：照片（支持批量）、原声录音（建议 ≥1 条）、文字故事、视频。
- 时间线：按时间自动/手动归类，形成"人生时间线"。

验收标准：单档案可容纳 ≥500 张照片、≥100 条录音；素材上传成功率 ≥99%。

### 6.3 授权管理（P0）

- 知情同意：支持两种授权路径——故人生前预授权（视频/书面记录）或两名近亲共同确认。
- 授权记录：记录授权人、时间、授权范围、用途；全程可审计。
- 关闭机制：任何家庭成员可申请永久关闭故事问答等 AI 能力。

验收标准：无有效授权则无法启用故事问答；授权记录可导出；机构不可代签或修改授权。

### 6.4 家族共享（P0）

- 家族树：支持三代以上关系录入与可视化。
- 邀请机制：邀请链接/二维码，实名验证后加入。
- 权限：创建者（管理）、共建者（上传/编辑）、访客（只读）。

验收标准：MVP 支持最多 3 名亲属共建；权限变更即时生效。

### 6.5 记忆馆（P0）

- 照片墙、原声录音库、故事集。
- 纪念册：模板化静态生成（非 AI），支持导出 PDF/打印。

验收标准：核心内容 3 步内可达；纪念册生成 <30 秒。

### 6.6 节日关怀（P0）

- 事件日历：生日、忌日、清明、春节等可配置。
- 推送规则：每日主动推送 ≤1 条；21:00-8:00 静音；可全局关闭。
- 内容来源：优先使用故人原声/原话，其次为家族共同撰写的内容。

验收标准：推送可配置、可关闭；误推送投诉率 <0.5%。

### 6.7 故事问答（P1 试点灰度）

- 输入：文字提问。
- 输出：基于记忆档案生成的文字回复，风格可配置（慈祥、幽默、严谨等）。
- AI 标识：对话界面常驻"AI 生成"标识；首次进入有明确提示。
- 防沉迷：连续使用超 2 小时提醒；检测到极端情绪时提供安抚与求助入口。
- 安全过滤：敏感词拦截、不生成诱导自伤内容、不冒充现实事务（如借钱）。
- 未成年人限制：未成年人账号不可使用。

验收标准：平均回复延迟 <15 秒；不当内容拦截率 100%（人工复核兜底）；对话记录随档案删除级联清理。

### 6.8 B 端合作后台（P1 试点）

机构角色、页面、流程、权限与结算的完整设计见第七章《B2B2C 渠道产品设计》。

验收标准：单机构从扫码到建档 ≤5 分钟；对账单可导出且金额与订单一致；员工无法查看客户隐私素材内容。

### 6.9 后台管理（P1 内部）

平台运营端角色、模块、流程与审计要求见第八章《后台管理（平台运营端）设计》。

验收标准：删除请求 72 小时内处理率 100%；后台敏感操作审计覆盖率 100%；机构结算审核可完整走通。

## 七、B2B2C 渠道产品设计

### 7.1 目标与原则

目标：让殡仪馆/公墓能低门槛地引导家属使用忆联，形成"机构获客 → 家属建档 → 服务付费 → 机构分成"的闭环，且可复制、可结算、可审计。

设计原则：

- 一线员工零学习成本：扫码即用，话术化引导。
- 机构最小权限：只能引导与运营，不能获取客户隐私数据内容。
- 结算透明：每笔订单分成可追溯，对账单可导出。
- 合规优先：知情同意必须由家属本人完成；数据权始终在家族，机构不可拦截删除。

### 7.2 渠道类型与角色

| 角色 | 场景 | 核心需求 | 权限范围 |
| --- | --- | --- | --- |
| 机构管理员（经理） | 管理员工、查看运营数据、对账 | 仪表盘、员工管理、结算中心 | 员工账号管理、数据查看、对账 |
| 一线员工（前台/客服/礼仪师） | 引导家属扫码、协助建档 | 扫码引导、代办建档、话术 | 建档引导、代办建档（家属现场确认）、查看订单状态 |
| 机构财务 | 核对订单与分成 | 对账单、结算记录 | 只读结算数据、导出对账单 |
| 平台侧（我方） | 签约、配置分成、风控 | 渠道管理后台、风控 | 全量管理、分成配置、审计 |

权限红线：机构所有角色默认不可查看家属的对话内容、隐私素材与授权记录明细；查看素材需逐次授权并留痕。

### 7.3 合作生命周期

1. 签约入驻：意向书 → 试点协议 → 开通机构账号。
2. 配置上线：员工账号与角色开通、二维码/物料生成、分成比例配置。
3. 引导建档：家属扫码 → 机构协助 → 知情同意由家属完成。
4. 服务交付：纪念册、存储扩容、机构定制服务等订单。
5. 分成结算：月度对账 → 结算 → 开票。
6. 续约/退出：数据交接、机构关系终止、家属权益保障（删除请求优先）。

### 7.4 核心页面与功能

| 页面 | 功能 | 说明 |
| --- | --- | --- |
| 机构仪表盘 | 今日扫码/建档/订单/收入、趋势、员工排行 | 机构管理员可见 |
| 员工管理 | 账号开通、角色配置、禁用、操作日志 | 机构管理员操作，操作留痕 |
| 扫码与物料 | 二维码/纪念码生成、海报/台卡模板、物料下载 | 每机构独立二维码 |
| 订单管理 | 订单列表、状态、退款、售后 | 机构可见本机构订单 |
| 结算中心 | 分成比例、结算周期、对账单、导出 | 金额与订单一致，可审计 |
| 素材传输 | 批量上传素材（加密传输）、素材状态 | 由家属或机构在授权范围内操作 |
| 合规与支持 | 隐私协议展示、授权状态查看（不展示内容）、投诉与关闭请求入口 | 机构不可修改授权与删除数据 |

### 7.5 关键流程

1. 家属扫码建档：扫码 → 进入机构专属纪念服务页 → 注册 → 建档 → 知情同意（家属本人操作）→ 生成档案。
2. 机构代办建档：一线员工登录后台 → 输入家属手机号/发起验证 → 家属确认 → 建档；机构不可代签知情同意。
3. 订单与分成：家属购买服务 → 平台收款 → 月度对账 → 按比例分成 → 机构提现/开票。
4. 家属退出与数据删除：家属申请 → 72 小时内处理；机构不可拦截或删除。

### 7.6 权限与合规要求

- 员工默认只读/引导权限；查看隐私素材需逐次授权且留痕。
- 机构不可查看家属对话内容、不可修改授权记录。
- 所有机构操作写入审计日志；离职员工账号及时禁用。
- 家属数据删除请求优先于机构利益。

### 7.7 结算规则（试点版）

| 订单类型 | 默认分成（平台/机构） |
| --- | --- |
| 纪念册定制 | 70% / 30% |
| 云端存储扩容 | 80% / 20% |
| 机构定制服务（人生微电影等） | 一事一议 |

- 结算周期：月度（次月 10 日前出对账单，15 日前结算）。
- 对账单字段：订单号、时间、订单类型、金额、分成比例、平台/机构金额、状态。

### 7.8 渠道 KPI

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 机构激活率 | 签约后 2 周内完成配置并产生首个建档 | ≥80% |
| 扫码→建档转化率 | 扫码后 7 天内建档的比例 | ≥60% |
| 月均订单 | 每活跃机构月均订单数 | 试点期 ≥10 单 |
| 机构续约率 | 试点结束后愿意继续合作的比例 | ≥70% |
| 渠道投诉率 | 渠道相关投诉占机构订单比例 | <1% |

- 合作方案一页纸。
- 机构培训手册（含引导话术与结算说明）。
- 演示脚本（家属视角 + 机构视角）。
- 结算对账模板。

## 八、后台管理（平台运营端）设计

### 8.1 目标与原则

目标：支撑平台运营、内容审核、伦理合规、风控审计与机构管理，保证三端闭环可运营、可审计、可处置。

设计原则：

- 最小权限：运营、审核、合规、财务、客服按角色分权。
- 合规优先：删除请求、投诉工单有 SLA 与留痕。
- 审计完备：所有查询、导出、删除、审核操作可追溯。
- 运营效率：常用操作 3 步内完成。

### 8.2 角色与权限

| 角色 | 场景 | 核心需求 | 权限范围 |
| --- | --- | --- | --- |
| 超级管理员 | 系统配置、账号管理 | 全量配置、角色分配 | 全量 |
| 运营人员 | 内容/模板/推送/活动 | 运营配置、数据看板 | 运营模块 |
| 审核人员 | 问答日志、敏感内容、投诉工单 | 审核队列、处置 | 审核模块（只读用户数据 + 处置） |
| 合规专员 | 知情同意记录、删除请求、数据导出 | 合规队列、SLA 监控 | 合规模块 |
| 财务人员 | 结算审核、打款 | 机构结算审核、对账 | 财务模块 |
| 客服人员 | 投诉、求助、关闭请求 | 工单处理 | 客服模块 |

权限红线：审核/客服查看用户数据需记录理由并留痕；数据导出需合规专员审批；删除操作双人复核。

### 8.3 核心模块与页面

| 模块 | 页面/功能 | 说明 |
| --- | --- | --- |
| 用户与家族管理 | 用户查询（手机号/ID）、账号状态、家族档案概览、举报处理 | 仅运营/合规需要时可查 |
| 内容与安全审核 | 故事问答日志检索、敏感拦截记录、人工复核队列、AI 标识核验 | 审核人员使用 |
| 伦理与合规 | 知情同意记录查询、删除请求队列（72h SLA）、投诉工单、数据导出审批 | 合规专员使用 |
| 机构管理 | 机构列表、分成比例配置、结算审核与打款、停用/退出 | 财务/超级管理员使用 |
| 风控与审计 | 操作日志、异常行为告警（机构越权、批量删除、高频问答） | 超级管理员使用 |
| 运营配置 | 纪念册模板、推送内容、活动与公告、Banner | 运营人员使用 |
| 数据看板 | 建档/留存/付费/渠道/问答质量/成本看板 | 分角色可见 |

### 8.4 关键流程

1. 删除请求处理：家属申请 → 后台工单 → 合规专员核验 → 双人复核 → 72 小时内删除 → 通知家属。
2. 投诉/舆情处理：投诉/举报 → 客服受理 → 审核处置 → 反馈用户 → 必要时升级。
3. 结算审核：机构对账单 → 财务复核 → 打款 → 回执归档。
4. 机构退出：停用账号 → 数据交接 → 家属权益确认（删除请求优先）。
5. 内容审核：问答拦截记录 → 人工复核 → 处置（下线/封禁/优化提示词）。

### 8.5 合规与审计要求

- 后台所有查询、导出、删除、审核操作写审计日志，保存 ≥6 个月（按监管要求执行）。
- 删除操作双人复核（操作人 + 复核人）。
- 数据导出需审批并加密传输。
- 后台账号开启双因素认证；离职账号即时禁用。

| --- | --- |

| 投诉 24 小时内响应率 | ≥95% |
| 敏感内容人工复核时效 | ≤24 小时 |
| 结算按时完成率 | 100% |
| 后台操作审计覆盖率 | 100% |

## 十、AI 能力说明

### 10.1 原则

MVP 仅包含文字故事问答一项 AI 能力；不开发任何"以 AI 生成逝者声音或形象"的功能。声音克隆、影像生成、AI 语音朗读等能力仅在伦理评审、合规备案与技术储备评估通过后，于后续版本启动。

### 10.2 技术路线

| 能力 | 方案 | 输入 | 输出 | 状态 |
| --- | --- | --- | --- | --- |
| 故事问答 | Qwen-1.8B-Chat / ChatGLM3-6B（建议评估升级） | 文本 | 文字回复 | MVP（P1 试点灰度） |
| 人格定制 | 提示词级风格配置（MVP）；LoRA 微调（后续） | 家族提供的性格描述 | 风格化回复 | MVP（简化）/后续迭代 |
| 记忆检索 | 记忆档案结构化检索（MVP）；FAISS 向量检索（后续） | 记忆档案/历史对话 | 上下文召回 | MVP（简化）/后续迭代 |
| 声音克隆 | Coqui XTTS-v2 / So-VITS-svc | ≥5 分钟清晰语音 | TTS 接口，支持 SSML | 后续迭代 |
| 视频/影像生成 | Wav2Lip + GFPGAN | 正脸照片+文本/音频 | 10 秒 MP4 | 后续迭代 |
| AI 语音朗读 | TTS 朗读文字回复 | 文本 | 语音 | 后续迭代 |

### 10.3 评估机制

- 故事问答：回复相关性、风格符合度、不当内容拦截率；试点问卷满意度 ≥4/5。
- 声音/影像等后续能力：声音相似度认可率 ≥70%、视频评分 ≥3.5/5（启动时执行）。
- 未达标不交付；提供降级方案（如回退模板化回复）。

### 10.4 红线

- 故事问答不模仿故人做出现实承诺（如处理财产、借款、法律事务）。
- 不生成可能造成二次伤害的内容；检测到极端情绪时引导求助。
- 所有 AI 生成内容（文字）带"AI 生成"标识；不得用于仿冒、诈骗或商业宣传。

## 十三、伦理与法律合规

### 13.1 必须建立的机制

- 知情同意制度：故人生前可预授权，或由两名近亲共同确认；授权记录可审计；机构不可代签。
- 关闭开关：任何家庭成员可申请永久关闭故事问答等 AI 能力，72 小时内处理。
- 防沉迷设计：每日最多 1 条主动推送，夜间静音；故事问答连续使用超 2 小时提醒。
- 极端情绪干预：检测到极端情绪时提供安抚文案、求助入口与紧急联系人。
- 数据归属：数据属于家族共有资产，不可商用；不向第三方提供用户数据；机构不可获取客户隐私内容。
- 未成年人保护：不向未成年人提供虚拟亲属/伴侣类服务；未成年人账号不开放故事问答。
- AI 标识：故事问答界面常驻"AI 生成"标识。
- 后台合规：删除双人复核、审计日志、数据导出审批（详见第八章）。

### 13.2 合规对照表

| 监管要求（暂行办法等） | 产品落地措施 |
| --- | --- |
| 拟人化互动安全责任 | 故事问答上线前完成安全评估与算法备案准备 |
| 不得向未成年人提供虚拟亲属/伴侣服务 | 实名年龄核验；未成年人账号不开放故事问答 |
| 防止诱导情感依赖/沉迷 | 主动推送限量；连续使用超 2 小时提醒；克制型回复设定 |
| 极端情绪干预 | 情绪识别、安抚文案、求助入口、紧急联系人 |
| 交互数据可复制、删除 | 数据导出；永久删除（含对话记录）；机构不可拦截；删除 SLA 72 小时 |

## 十四、商业试点与运营

### 14.1 试点目标

- 合作 1-2 家殡仪馆/公墓，服务 50-100 个家庭。
- 验证"建档完成率、留存、付费转化"三组核心数据，以及故事问答满意度。
- 验证渠道闭环：扫码→建档→订单→分成结算全流程可跑通。
- 验证后台运营闭环：删除请求、投诉工单、问答审核、结算审核可处置。

### 14.2 试点内容

- 免费提供：记忆档案、家族共建、纪念册、节日关怀。
- 灰度开放：故事问答（文字，前 20 个家庭，AI 标识 + 防沉迷）。
- 付费测试：高级纪念册、云端存储扩容、机构定制纪念服务（渠道合作）。
- 后台运营：删除请求 72 小时 SLA、投诉工单、问答人工复核、机构结算审核。
- 反馈收集：可用性访谈、满意度问卷、伦理体验回访（第 30/90 天）。
- 不开放：AI 语音朗读、声音克隆、影像复活、AI 老照片修复。

### 14.3 成功指标

| 指标 | 目标 |
| --- | --- |
| 建档完成率 | ≥60% |
| 7 日留存 / 30 日留存 | ≥30% / ≥15% |
| 试点付费转化率 | ≥5% |
| 纪念册满意度 | ≥4/5（问卷） |
| 故事问答满意度 | ≥4/5（问卷） |
| 机构激活率 | ≥80% |
| 删除请求 72 小时内处理率 | 100% |
| 投诉率 | <1% |
| 强制关闭请求处理时长 | ≤72 小时 |

### 14.4 成本控制

- 纪念册模板化生成，静态资源 CDN 分发。
- 分级存储：原素材压缩存储，冷数据归档。
- 故事问答按需调用与缓存，控制推理成本。
- 机构合作为主要收入来源，C 端订阅为补充。
