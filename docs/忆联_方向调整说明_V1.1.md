# 忆联（MemoryLink）方向调整说明 V1.1

日期：2026年9月3日

状态：定稿（安全边界已于 2026-09-03 确认）

关联文档：《忆联（MemoryLink）产品需求说明书 V1.7》、《市场可行性报告 V1.4》

## 一、背景与结论

原产品定位以"纪念故人"为核心（数字纪念馆）。现决定将业务框架调整为：**家族记忆与亲情连接平台**——记录每一位家人的故事，连接家族成员之间的记忆与情感，无论亲人是否在身边。

两项决策：

1. 在世成员功能（成员主页、共同回忆、口述历史）纳入 MVP；
2. 故事问答面向**所有人**开放（满足启用条件的前提下）。

## 二、产品定位（新）

忆联 = 家族记忆与亲情连接平台。

- 记录：每一位家人的故事、口述与影像，无论在世或已故；
- 传承：家族历史、家风、共同回忆的跨代留存；
- 连接：家族成员围绕共同记忆进行分享与互动；
- 告别：纪念故人仍是重要场景之一，但不再是唯一中心。

## 三、核心对象模型（人物档案双态）

系统核心从"故人档案"演进为**人物档案**：

- 每家族成员（含自己在内）可拥有个人档案；
- 人物档案分为两类状态：
  - 在世成员：本人可维护自己的档案与口述，需本人同意；
  - 故人：由近亲属共同维护，需知情同意；
- 家族树覆盖所有成员，人物可标记在世/故人，并展示"与我"的关系。

落地说明：现有 loved_ones 表在 V3 迁移中增加 `is_deceased`（默认 TRUE，兼容存量故人数据）等字段，代码与接口术语渐进调整，不强制一次性改表名。

## 四、MVP 范围调整（在世成员功能纳入）

| 模块 | 说明 | 优先级建议 |
| --- | --- | --- |
| 成员主页 | 每位家族成员（含自己）的档案页：基本信息、自述、照片/录音、可编辑 | P0 |
| 共同回忆 | 家族共享相册/时间线/事件（聚会、旅行、节日），多人共建 | P0 |
| 口述历史 | 在世长辈"我的讲述"录音/视频 + 文本整理，本人管理、可授权家人回看 | P0 |
| 家族树增强 | 人物含在世/故人标记；展示与我的关系；邀请码加入沿用 | P0 |
| 故事问答 | 面向全部人物（规则见第五章） | P1 |
| 故人纪念场景 | 告别仪式、忌日/清明提醒、纪念册等保留为场景模块 | P0（试点） |

## 五、AI 故事问答规则（对所有人）

启用条件：

1. 在世成员：本人**主动开启**"我的数字讲述"并完成实名核验；回答仅基于本人上传的口述与资料；可随时关闭；关闭后立即不可问答。
2. 故人：沿用现行规则——存在 VALID 的知情同意记录（生前预授权或两名近亲共同确认）。
3. 在世未成年人：默认不开放 AI 问答（监护人也不可开启）。
4. 任何未满足启用条件的人物均不可被问答。

红线（沿用并强化）：

- 不编造档案之外的事实；
- 不冒充本人处理现实事务（金钱、法律、医疗等）；
- 所有 AI 生成内容带标识；
- 防沉迷：连续使用提醒、极端情绪支持话术；
- 任何人可申诉、申请关闭对应人物的问答。

## 六、合规与伦理调整

| 对象 | 合规基础 |
| --- | --- |
| 在世成员 | 本人同意（PIPL）；声音/人脸等敏感信息单独授权；数据可导出、可删除；未成年人默认不开放 AI 问答 |
| 故人 | 近亲属知情同意、永久关闭开关（现行机制） |
| AI 拟人化互动 | AI 标识、使用时长提醒、极端情绪干预、算法备案（按监管执行） |

## 七、数据与页面改造清单（后续版本执行）

数据（Flyway V3 起）：

- loved_ones 增加 `is_deceased`（默认 true）、`person_status`；
- 增加"口述历史"记录（媒体 + 文本整理），或复用 media_files + 新增字段；
- 人物问答启用开关：`ai_persona_enabled`（本人/授权开启）、开启人与时间留痕；
- family_members 关系语义扩展：既支持"与家族的关系"，也支持人物间关系（家族树边，后续迭代）。

页面/交互：

- 首页重构：我的家人、共同回忆、纪念场景入口；
- 档案详情页支持双态（在世显示"我的讲述/管理授权"，故人显示"知情同意"）；
- 新增"成员主页"与"我的讲述"管理页；
- 故事问答入口对满足启用条件的人物开放，未启用时显示原因与开启引导。

## 八、试点建议

试点仍可先跑通"故人纪念 + 家族共建"闭环（殡葬渠道），但在世成员功能（成员主页、共同回忆、口述历史）与数据模型在 MVP 开发期内一并落地，避免二次迁移。

## 九、已确认的安全边界（2026-09-03）

1. ✅ 在世成员的故事问答必须由本人主动开启授权；其他人（包括子女替父母）不能代为开启。
2. ✅ 在世未成年人不开放 AI 问答。
