# 忆联（MemoryLink）系统启动手册

版本：V1.0

更新日期：2026年9月8日

项目根目录：/home/dev/projects/MemoryLink

## 一、模块与端口总览

| 模块 | 目录 | 端口/地址 | 说明 |
| --- | --- | --- | --- |
| PostgreSQL | 本机服务 | 5432 | 数据库（库/用户 memorylink） |
| Redis | docker-compose | 6379 | 缓存/队列/防沉迷计数 |
| MinIO | docker-compose | 9000 / 9001 | 对象存储（S3 兼容），控制台 9001 |
| 后端 server | server/ | 8080 | Spring Boot API |
| B 端 web | web/ | 5173 | 机构后台（React+Vite） |
| 后台管理 admin | admin/ | 5174 | 平台管理（React+Vite） |
| C 端 app | app/ | 5180（Web 预览） | Flutter 家属端 |

访问地址统一使用局域网 IP：http://192.168.32.128:PORT

## 二、前置条件

- Java 21、Maven 3.8+（后端）
- Node.js 18+、npm（web/admin）
- Flutter SDK（已安装在 /home/dev/flutter，stable 3.47.2）
- Docker + docker-compose（Redis/MinIO）
- 本机 PostgreSQL 服务（schema memorylink 已建好）
- 项目根目录存在 .env（含 DeepSeek API Key 等），从 .env.example 复制生成

检查环境：

```bash
java -version
mvn -version
node -v
export PATH=/home/dev/flutter/bin:$PATH && flutter --version
pg_isready -h localhost -p 5432
```

## 三、一键启动（推荐）

```bash
cd /home/dev/projects/MemoryLink
scripts/start-all.sh
```

脚本会依次启动：

1. Redis + MinIO（docker-compose）
2. 后端 server（8080）
3. B 端 web（5173）
4. 家属端 Flutter Web（5180）

查看日志：

```bash
tail -f logs/backend.log   # 后端
tail -f logs/web.log       # B 端 web
tail -f logs/app-web.log   # 家属端（首次编译较慢，等待 "is being served"）
```

停止全部：

```bash
scripts/stop-all.sh
```

## 四、分模块启动

### 1. PostgreSQL（本机服务）

```bash
pg_isready -h localhost -p 5432
# 未运行时（Ubuntu 示例）
sudo systemctl start postgresql
```

连接信息：host localhost:5432，库 memorylink，schema memorylink，用户 memorylink/memorylink。

### 2. Redis + MinIO（容器）

```bash
cd /home/dev/projects/MemoryLink
docker-compose -f docker-compose.dev.yml up -d
```

MinIO 控制台：http://192.168.32.128:9001（memorylink/memorylink123）。

### 3. 后端 server（8080）

```bash
cd /home/dev/projects/MemoryLink/server
set -a && source ../.env && set +a
mvn spring-boot:run
```

验证：

```bash
curl http://localhost:8080/api/v1/ping
```

接口文档：http://192.168.32.128:8080/swagger-ui.html

测试：`mvn test`

### 4. B 端机构后台 web（5173）

```bash
cd /home/dev/projects/MemoryLink/web
npm install        # 首次或依赖变更后
npm run dev
```

验证：浏览器打开 http://192.168.32.128:5173

测试/构建：`npm test` / `npm run build`

### 5. 平台后台管理 admin（5174）

```bash
cd /home/dev/projects/MemoryLink/admin
npm install
npm run dev
```

验证：浏览器打开 http://192.168.32.128:5174

### 6. C 端家属端 Flutter

Web 预览（推荐联调）：

```bash
export PATH=/home/dev/flutter/bin:$PATH
cd /home/dev/projects/MemoryLink/app
flutter pub get
flutter run -d web-server \
  --web-hostname 0.0.0.0 \
  --web-port 5180 \
  --dart-define=API_BASE=http://192.168.32.128:8080
```

验证：浏览器打开 http://192.168.32.128:5180

Android 模拟器：

```bash
flutter run --dart-define=API_BASE=http://10.0.2.2:8080
```

真机（与服务器同一局域网）：

```bash
flutter run --dart-define=API_BASE=http://192.168.32.128:8080
```

测试/检查：`flutter analyze` / `flutter test`

## 六、常见问题

1. 刷新页面回到登录页或提示"登录已过期"：令牌有效期 2 小时，重新登录即可；已被强制刷新的页面请 Ctrl+F5。
2. 页面提示"加载失败，请确认后端服务已启动"：确认 8080 在运行、浏览器能访问 http://192.168.32.128:8080/api/v1/ping。
3. MinIO 预签名地址指向 localhost：确认 .env 中 MINIO_ENDPOINT=http://192.168.32.128:9000 且已重启后端。
4. Flutter Web 首次启动慢：等待 app-web.log 出现 "is being served"。
5. npm 安装慢/失败：网络恢复后重试 `npm install`；node_modules 已装时可跳过。
6. 端口被占用：`ss -ltn | rg ':(8080|5173|5180|6379|9000)\b'` 定位后停掉旧进程或用 scripts/stop-all.sh。
7. DeepSeek 问答报"AI 服务未配置"：检查 .env 的 DEEPSEEK_API_KEY 并重启后端。
